
This zip includes 3 files, all of which you will need to modify as part of this lab: filter.c, filter.h, and main.c.

filter.c
filter.c includes 3 functions that you must complete. You may change the name used for parameters, but you may not change the type of these parameters.

void print_array(int to_print[])

You are to print the provided integer array. All provided arrays will be of length MAX_ELEMENTS, a value defined in filter.h.
All elements other than the final element is to be followed by a comma
The final element is to be followed by a new line
Example outputs for the entire program are found in the “Example Output” section below


void filter_evens(int origin_array[], int to_array[])

You are provided two arrays of length MAX_ELEMENTS
You must copy all even integers from the first array to the second array.
The second array should be populated in order, there should not be gaps created due to a distance between elements in the original array
0 is to be considered as even for this function.
There will be space left at the end of the new array, fill all remaining slots with 0
Example: an origin array of [0,1,2,3,4,5] would fill the second array with [0,2,4,0,0,0]


void filter_odd_indexes(int origin_array[], int to_array[])

You are provided two arrays of length MAX_ELEMENTS
You must copy all elements at odd indexes to the second array
The second array should be populated in order, there should not be gaps created due to a distance between elements in the original array
0 is to be considered as even for this function.
There will be space left at the end of the new array, fill all remaining slots with 0



Example: an origin array of [9,8,7,6,5,4] would fill the second array with [8,6,4,0,0,0]
filter.h
filter.h is the header file for filter.c. You are to complete this header file so that all functions from filter.c are properly declared.

You must also write the include guard.

main.c
Your main file should, after the code provided for generating an array, perform the following tasks:

Print the generated array with the print_array function you wrote
Create necessary variable(s) and call the filter_evens function you wrote
Print the filtered array with the print_array function
Create necessary variable(s) and call the filter_odd_indexes function you wrote
Print the filtered array with the print_array function

Requirements & Rules
Use inline (//) comments to explain complex lines or lines where behavior may not be obvious to a reader.
You may not assume that a created array will automatically be populated with 0s.
You may take any approach to have 0s fill the final elements of the array you copy to, but there must be code present to accomplish this task
You must complete all 3 functions in filter.c, implement the required functionality in main.c and complete the header file filter.h
You may not alter function signatures beyond changing the names of parameters.
You may not hardcode any output
You may not alter the code for generating the origin array found in main.c
Your function must compile without any warnings or errors produced by the compiler with the -Wall or -Wextra arguments
